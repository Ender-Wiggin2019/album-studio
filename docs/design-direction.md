# 电子相册工作室：界面设计方向

## 产品定位

- **对象**：离线、本地的家庭与旅行相册。
- **用户**：不熟悉文件格式、命令行和工程术语的 Windows/macOS 用户。
- **核心任务**：选择本地照片，整理成册，继续编辑并导出带封面的 PDF。
- **视觉隐喻**：安静的摄影看样台。应用负责组织和编辑；相册主题负责成品表达。

应用外壳固定使用中性冷灰色，不跟随相册主题变色。主题只作用于封面、相册页面、整册预览和 PDF。避免营销页式大标题、玻璃卡片、装饰渐变和无意义数据看板。

## 记忆点

页面画布始终呈现真实纸张比例、装订安全区和页边；左侧页面缩略图像一本摊开的相册页签。胶片编号、套准标记等细节只用于帮助用户识别页面和打印边界，不作为无功能装饰。

## 信息架构

```text
项目首页
├── 新建相册
├── 打开相册
├── 最近项目
└── 导入旧相册 → 迁移预览 → 导入为新项目

项目工作区
├── 素材库 → 导入 → 选择 → 添加到相册
├── 排版 → 封面 / 页面 / 照片 / 文字
├── 照片编辑 → 裁剪 / 缩放 / 旋转 / 蒙版 / 滤镜
└── 整册预览 → 导出 PDF
```

“选择素材”是素材库中的任务状态，不增加一个长期导航层。项目内容与会话 UI 状态分开保存；当前模块、当前选择、画布缩放和面板开关不能写入项目文档。

## 布局

### 宽屏（≥ 1280 px）

```text
┌ 返回项目  项目名 | 素材库 排版 | 已保存  撤销 重做 | 预览 [导出 PDF] ┐
├────────────┬──────────────────────────────────┬──────────────┤
│ 页面 224px │                                  │ 属性 320px   │
│ 封面       │          A4 横向页面画布          │ 当前对象身份 │
│ 第 1 页    │                                  │ 分组控件     │
│ 第 2 页    │                                  │              │
│ + 添加页面 │          适合窗口 · 100%          │              │
└────────────┴──────────────────────────────────┴──────────────┘
```

根节点固定为 `100dvh` 且不滚动。页面栏、画布和属性栏各自拥有明确的滚动边界；画布永远是最大区域。

### 中等宽度（960–1279 px）

- 页面栏缩至约 152 px。
- 属性栏改为右侧 Sheet，由“属性”按钮打开。
- 画布仍是中央主任务，撤销/重做允许使用带 Tooltip 的图标按钮。

### 窄窗口（< 960 px）

```text
┌ 返回  项目名 · 已保存                         [导出] [更多] ┐
├──────────────────────────────────────────────────────────┤
│                                                          │
│                    相册页面画布                           │
│                                                          │
├──────────────────────────────────────────────────────────┤
│ 封面 │ 1 │ 2 │ 3 │ … │ +              横向页面胶片条     │
└──────────────────────────────────────────────────────────┘
```

属性使用全高 Sheet，页面栏变成底部胶片条；根页面不能出现水平滚动。Electron 建议最小窗口为 `800 × 640`。

## 操作与状态边界

每个上下文只有一个高强调主操作：项目首页“新建相册”、空素材库“选择照片文件夹”、素材选择态“添加到相册”、排版“导出 PDF”、照片编辑“应用到照片”、迁移“导入为新项目”。

- 页面、主题、文字和属性变更即时进入文档，约 500 ms 自动保存，可撤销/重做。
- 照片裁剪使用草稿；只有“应用到照片”才提交为一个撤销步骤。
- 自动保存失败必须持续显示并提供重试，不能只显示瞬时 toast。
- 导出弹窗保持打开，按“准备页面 / 等待图片与字体 / 写入文件”展示阶段进度。Electron 打印阶段不伪造逐页进度。
- 普通移除优先 toast 撤销；整页删除和清空相册使用 AlertDialog。
- 空状态、筛选无结果、导入中、部分失败、素材缺失和项目损坏采用不同状态与恢复动作。

## 主题 Token

主题 token 只挂在 `[data-album-theme]` 下，不能覆盖 shadcn 的应用级 `--background`、`--primary` 等变量。

| Token | 旅途手账 `journal` | 海风明信片 `postcard` | 胶片画廊 `film` |
| --- | --- | --- | --- |
| `album-canvas` | `#E7DED1` | `#DDEDEF` | `#141512` |
| `album-page` | `#FFF8EC` | `#FFFDF7` | `#F6EDD8` |
| `album-page-alt` | `#EAD8BE` | `#D7EEF0` | `#20211D` |
| `album-ink` | `#231F1A` | `#17333C` | `#181915` |
| `album-muted` | `#73695D` | `#5F7175` | `#6E6A5F` |
| `album-rule` | `#CCBCA6` | `#B8D4D7` | `#C8BEA8` |
| `album-accent` | `#A84835` | `#E9654C` | `#C94B38` |
| `album-accent-alt` | `#2E6F6C` | `#127C8A` | `#9CB57B` |

- `journal`：装订留白、日期地点批注、轻纸纹和纸边蒙版。
- `postcard`：正反明信片结构、地址线、邮戳和邮票边蒙版。
- `film`：接触印样编号、曝光边码、深色片框与几何蒙版。

应用 UI 使用系统字体栈；相册导出字体随应用打包，并在 Windows/macOS 上使用同一字体文件，避免换行漂移。

## 业务组件

- `ProjectIdentity`、`AssetIdentity`、`AssetGrid`
- `PageRail`、`AlbumCanvas`、`AlbumPageView`
- `SelectionActionBar`、`ContextInspector`
- `PhotoEditWorkspace`、`ThemePreviewCard`
- `ExportProgressDialog`、`LegacyMigrationDialog`

集合不机械套用 Table 或 Card；页面缩略图不用通用 Sidebar；ContextMenu 不能成为非技术用户的唯一入口。shadcn 负责基础组件和交互语义，图片网格、页面画布与缩略图栏由业务组件实现。

## 视觉验收

- `1440 × 900`：三栏完整可见，画布面积最大。
- `1100 × 720`：属性 Sheet 生效，无根水平滚动。
- `800 × 640`：底部页面胶片条、单主画布、头部操作不挤压。
- 应用外壳不随主题变色；主题只影响封面、页面、预览和 PDF。
- 三套主题的封面与 1/2/4/6 图页均有视觉回归截图。
- 编辑、预览和 PDF 使用同一布局模型，裁剪、旋转、蒙版和文字换行一致。
- 长中文项目名、长文件名和长错误消息不撑破布局。
- 选择、缺失、重复和错误状态不只依赖颜色表达。
- 所有交互具备 hover、active、disabled 与 `focus-visible` 表达。

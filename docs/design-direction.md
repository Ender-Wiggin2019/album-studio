# 咔宝：界面设计方向

## 产品定位

- **对象**：离线、本地的家庭与旅行相册。
- **用户**：不熟悉文件格式、命令行和专业设计软件的 Windows/macOS 用户。
- **核心任务**：导入本地照片，用模板快速起稿，像 Slides 一样自由排版，继续裁剪美化并导出。
- **视觉隐喻**：安静的摄影看样台。应用负责组织和编辑；相册主题负责成品表达。

桌面与浏览器共用同一 Studio UI。平台差异通过 badge、capability 和明确文案表达：桌面版显示项目文件夹/PDF 能力，浏览器版必须持续说明 OPFS 与站点数据风险。

应用外壳固定使用中性冷灰色，不跟随相册主题变色。主题只作用于封面、相册页、预览和打印。避免营销页式大标题、玻璃卡片、装饰渐变和无意义仪表盘。

## 记忆点

页面画布始终呈现项目 PageSpec 的真实比例、装订安全区和页边。左侧缩略图像一本摊开的相册页签；选中图片、文字、Icon 或贴纸后出现的八向控制点、旋转手柄、吸附线和中心线是画布的主要交互语言。右侧“装帧托盘”始终围绕画布提供布局、素材、组件和当前 Block 编辑。

## 信息架构

```text
项目首页
├── 新建相册 → 名称 / 成品尺寸 / 主题 → 桌面位置或浏览器 OPFS
├── 打开相册文件夹（仅桌面）
└── 最近项目

项目工作区
├── 页面栏 → 封面 / 内容页 / 新增 / 移动 / 删除
├── 自由画布 → 统一 Block 选择 / 拖动 / 缩放 / 旋转 / 吸附
├── 装帧托盘 → 布局 / 项目素材 / 文字与装饰组件 / 条件 Block 编辑
├── 照片编辑 → 裁剪 / 框内变换 / 滤镜 / 蒙版
└── 整册预览 → 桌面 PDF 或浏览器打印
```

“选择素材”是素材标签中的任务状态，不增加长期导航层，也不卸载画布。项目内容与会话 UI 状态分离；当前 Block、右栏标签、富文本草稿、画布缩放和 Sheet 开关不写入 `AlbumDocument`。

## 工作区布局

### 宽屏（>= 1280 px）

```text
┌ 返回  项目名 · 已保存       撤销 重做       预览 [导出] ┐
├────────────┬────────────────────────────────┬──────────────────┤
│ 页面 224px │      当前 PageSpec 自由画布     │ 装帧托盘 360px   │
│ 封面       │   拖动 / 缩放 / 旋转 / 吸附    │ 布局 素材 组件   │
│ 第 1 页    │                                │ [Block 编辑]*    │
│ + 添加页   │          适合窗口 · 90%         │ * 选中时出现     │
└────────────┴────────────────────────────────┴──────────────────┘
```

根节点为 `100dvh` 且不滚动。页面栏、画布和属性栏各自拥有明确的滚动边界；画布始终是最大区域。

### 中等宽度（960–1279 px）

- 页面栏缩至约 152 px。
- 装帧托盘改为右侧 Sheet，由同名按钮打开。
- 画布仍是中央主任务，撤销/重做可使用带 Tooltip 的图标按钮。

### 窄窗口（< 960 px）

```text
┌ 返回  项目名 · 已保存                    [导出] [更多] ┐
├─────────────────────────────────────────────────────────────┤
│                       相册页面画布                       │
├────────────────────────────────────────────────────────────┤
│ 封面 │ 1 │ 2 │ 3 │ … │ +                 横向页面胶片条     │
└────────────────────────────────────────────────────────────┘
```

装帧托盘使用全高 Sheet，页面栏变成底部胶片条；根页面不得出现水平滚动。Electron 最小窗口为 800 × 640。

## 画布交互

- 点击任意 Block 显示 Moveable 控制框；拖动、八向缩放和旋转保持在页面内。
- 手势过程中只更新当前 DOM，结束时才提交一次文档命令和一个 undo 步骤。
- 吸附页面安全边距、水平/垂直中心、其他 Block 边界/间隙和常用旋转角度。
- 键盘微移、快速移动、复制和删除不应与输入框键盘交互冲突。
- 图层顺序有可见按钮；ContextMenu 和快捷键不能是非技术用户的唯一入口。
- 页面布局必须以不同视觉真实表达图片槽和文字槽；数量不匹配时明确禁用，DecorationBlock 不参与布局。

## 照片编辑边界

- 编辑使用草稿；“取消”不修改文档，“应用到照片”只生成一个命令。
- 裁剪按原图百分比恢复，框内旋转/翻转与页面元素旋转分开。
- 滤镜预设是 effects 的快速起点，同时提供亮度、对比度、饱和度、色相、复古、黑白、柔焦和暗角精细控制。
- 蒙版形状与裁剪/effects 一同出现在画布、缩略图、预览和打印。

## 操作与状态

每个上下文只有一个高强调主操作：项目首页“新建相册”、空素材标签“选择照片”、素材选择态“批量添加”、照片编辑“应用到照片”、工作区“导出 PDF/打印”。

- 普通文档修改在短暂停顿后自动保存，并可撤销/重做。
- 自动保存失败必须持续显示和提供重试，不能只显示瞬时 toast。
- 导出弹窗按“保存最新修改 / 等待图片 / 生成或打印”展示阶段，不伪造 Chromium 没有提供的逐页进度。
- 删除整页使用 AlertDialog；Block 删除有明确按钮与撤销。
- 空状态、搜索无结果、导入中、部分失败、素材缺失和项目损坏使用不同文案与恢复动作。

## 主题 Token

主题 token 只挂在 `[data-album-theme]` 下，不覆盖 shadcn 的应用级 `--background`、`--primary` 等变量。

| Token              | 旅途手账 `journal` | 海风明信片 `postcard` | 胶片画廊 `film` |
| ------------------ | ------------------ | --------------------- | --------------- |
| `album-canvas`     | `#E7DED1`          | `#DDEDEF`             | `#141512`       |
| `album-page`       | `#FFF8EC`          | `#FFFDF7`             | `#F6EDD8`       |
| `album-page-alt`   | `#EAD8BE`          | `#D7EEF0`             | `#20211D`       |
| `album-ink`        | `#231F1A`          | `#17333C`             | `#181915`       |
| `album-muted`      | `#73695D`          | `#5F7175`             | `#6E6A5F`       |
| `album-rule`       | `#CCBCA6`          | `#B8D4D7`             | `#C8BEA8`       |
| `album-accent`     | `#A84835`          | `#E9654C`             | `#C94B38`       |
| `album-accent-alt` | `#2E6F6C`          | `#127C8A`             | `#9CB57B`       |

- `journal`：装订留白、日期地点批注、轻纸纹和纸边蒙版。
- `postcard`：正反明信片结构、地址线、邮戳和邮票边蒙版。
- `film`：接触印样编号、曝光边码、深色片框与几何蒙版。

应用外壳优先使用系统中文字体栈，减少首屏体积。

## 组件所有权

- 页级：`ProjectsHome`、`StudioWorkspace`。
- 业务 feature：`ProjectAssetsPanel`、`ComponentLibraryPanel`、`PageLayoutPanel`、`PageRail`、`EditorWorkspace`、`RightPanel`、`PhotoEditWorkspace`、`PreviewWorkspace`。
- 统一渲染：`AlbumPageView`、`BlockView`、三类 Block View、`PrintBook`。
- 跨功能资源：`AssetImage`、`useAssetSource`。
- 通用 UI 原语：`packages/studio/src/components/ui`。

集合不机械套用 Table 或 Card；页面缩略图不用通用 Sidebar。浅层转发组件不应只为了目录整齐而存在。

## 视觉验收

- 1440 × 900：三栏完整可见，画布面积最大。
- 1100 × 720：属性 Sheet 生效，无根水平滚动。
- 800 × 640：底部页面胶片条、单主画布、头部操作不挤压。
- 桌面与浏览器共用页面视觉；平台文案和不支持的能力准确。
- 画布、缩略图、预览和打印中的几何、裁剪、滤镜、蒙版与文字一致。
- 长中文项目名、长文件名和长错误不撑破布局。
- 选中、缺失、重复和错误状态不只依赖颜色表达。
- 所有交互具备 hover、active、disabled 与 `focus-visible` 表达。

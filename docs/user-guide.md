# 电子相册工作室使用指南

## 1. 启动应用

获取已打包版本后：

- Windows：运行 NSIS 安装程序，或直接打开 portable `.exe`。
- macOS：打开 `.dmg`，将“电子相册工作室”拖入“应用程序”后启动。

内部测试包默认未用商店证书签名或公证，系统可能显示安全提示。请只使用项目维护者提供的产物。

## 2. 新建或打开相册

### 新建

1. 在首页点击“新建项目”。
2. 输入相册名称，选择“旅途手账”、“海风明信片”或“胶片画廊”。
3. 选择保存位置。应用会创建一个 `.album-project` 项目文件夹。

项目文件夹同时包含排版数据和导入后的原图副本。要备份或移动相册，请复制整个 `.album-project` 文件夹，不要只复制 `manifest.json`。

### 打开

点击“打开项目”，选择 `.album-project` 文件夹。也可以从“最近项目”打开。如果项目被移动，点击原卡片并重新选择它的新位置。

## 3. 导入与选择素材

1. 进入“素材库”。
2. 选择“导入图片”或“导入文件夹”。
3. 等待导入完成。应用会复制原图、生成预览图并按内容去重；源图不会被修改。
4. 勾选要排版的素材，选择加入当前页的空位，或创建新页自动分页。

无法解码、格式不支持或无法读取的文件会被跳过，导入结果会展示明细。

## 4. 排版与页面

- 封面始终是第 1 页，可在属性面板编辑标题、副标题和日期。
- 照片页可选择 1、2、4 或 6 图版式。
- 如果当前页已有照片，应用不允许切换到无法容纳它们的更小版式，避免误丢排版。
- 在页面菜单中向前/向后移动页面。
- 选中照片后，可以在当前页调整位置，或将它移到其他页的空位。
- 底部缩略图用于切换页面；放大/缩小只改变编辑视图，不影响 PDF。

## 5. 编辑照片和文字

选中一张照片，在属性面板点击“编辑照片”：

- 拖动取景位置，调整缩放。
- 按 90° 旋转，或水平/垂直翻转。
- 调整明亮度、对比度和饱和度。
- 选择无蒙版、圆角、圆形、拱形、手撕纸边、邮票或胶片框。
- 随时重置为默认参数。

所有操作只保存编辑参数，不重写原图。照片说明和页文字可调整字体、字号、字重、对齐、行高和颜色。顶部撤销/重做可恢复近期操作。

## 6. 主题、预览和 PDF

- 在项目属性中切换主题；主题作用于整本相册。
- 点击顶部眼睛按钮预览整册，确认封面、文字和照片裁剪。
- 点击 PDF 按钮，选择保存位置。导出为 A4 横向，包含封面。

导出开始后请保持应用运行，直到显示完成。如果导出失败，应用不会把未完整的临时文件当作成功 PDF。

## 7. 迁移旧相册

1. 在首页选择“迁移旧相册”。
2. 选择旧 `.json` 或自包含 `.html`。
3. 检查预检结果：标题、照片数、页数与警告。
4. 选择新项目的保存位置并完成迁移。

迁移会创建全新项目，不修改旧 JSON/HTML。旧项目中内容相同的 Base64 图片只保存一份原图，但保留每个页面放置。

## 8. 恢复和故障排查

### 照片显示缺失

在素材库或照片属性中点击“重新定位”，选择原图的另一份副本。应用会校验内容指纹；选错图时不会覆盖记录。

### 项目卡片无法打开

项目可能被改名或移动。点击最近项目卡片，然后重新选择 `.album-project` 文件夹。

### 导入或 PDF 很慢

大量高分辨率照片需要解码和生成预览图。请保证项目目录有足够空间，并等待阶段状态完成。长相册 PDF 可能需要数十秒。

### 如何做安全备份

关闭项目并复制整个 `.album-project` 文件夹到另一块磁盘。项目内部的 `backups/` 只是最近 manifest 备份，不能替代整个项目备份。

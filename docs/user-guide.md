# 咔宝使用指南

## 1. 选择桌面版还是浏览器版

|          | 桌面版                              | 浏览器版                           |
| -------- | ----------------------------------- | ---------------------------------- |
| 适合     | 长期编辑、归档和正式 PDF            | 轻量试用和界面调试                 |
| 项目位置 | 用户选择的 `.album-project/` 文件夹 | 当前网站 origin 的 OPFS            |
| 打开方式 | 可打开已有 `.album-project/`        | 只能打开该浏览器中的最近项目       |
| 导出     | Electron 直接生成 PDF               | 打开系统打印面板，可选“保存为 PDF” |
| 备份     | 复制整个项目文件夹                  | 当前没有文件夹归档导出             |

浏览器会尝试申请持久存储，但是否批准由浏览器决定。**清除站点数据、更换浏览器配置或使用无痕窗口，都可能丢失浏览器项目。** 需要可复制备份时请使用桌面版。

## 2. 启动

### 已打包桌面版

- Windows：运行 NSIS 安装程序，或直接打开 portable `.exe`。
- macOS：打开 `.dmg`，将“咔宝”拖入“应用程序”后启动。

内部测试包默认没有商店签名或公证，系统可能显示安全提示。只使用维护者提供的产物。

### 从源码启动

需要 Node.js 22.12.0 或更高版本。从仓库根目录双击：

- 桌面版：macOS 用 `dev.command`，Windows 用 `dev.cmd`。
- 浏览器版：macOS 用 `dev-web.command`，Windows 用 `dev-web.cmd`。

首次运行会自动安装依赖。保存代码后界面会热更新；浏览器版会自动打开本地页面。

## 3. 新建和打开相册

### 新建

1. 在项目首页点击“新建相册”。
2. 输入名称，选择 A4 横向、12 寸方形或 16:9 成品尺寸，再选择“旅途手账”、“海风明信片”或“胶片画廊”。
3. 桌面版再选择保存位置；浏览器版直接保存到 OPFS。

尺寸会用于整册所有页面，创建后不能更改。项目只使用当前 `AlbumDocument` v2；旧 image-only 项目会提示格式已更新，其他不符合 schema 的文件会明确报错。

### 打开

- 桌面版：点击“打开相册文件夹”，选择完整的 `.album-project/`；也可从“最近项目”打开。
- 浏览器版：从“最近项目”打开该 origin 中的项目，不会显示系统文件夹按钮。

备份或移动桌面项目时，必须复制整个 `.album-project/`，不要只复制 `manifest.json`。

## 4. 导入照片

1. 打开右侧“素材”标签；画布和页面栏会始终保留在工作区中。
2. 点击“选择图片”，或使用“选择照片文件夹”。
3. 等待原图安全保存和预览生成。
4. 点击单张素材可放到当前页面中央，也可直接拖到画布目标位置；多选后可批量添加到当前页或自动创建新页。

支持 JPEG、PNG、WebP 和 AVIF。图片内容按 SHA-256 去重；多个 ImageBlock 仍可以引用同一张原图。文件夹内容导入后按项目素材平铺，不创建虚拟目录。无法解码、像素超过 8000 万或格式不匹配的文件会被跳过，界面会保留原因。导入前的源图不会被修改。

## 5. 页面布局与 Block 自由画布

- 右侧“布局”标签会按当前图片和文字数量启用可用布局。布局只重排已有 ImageBlock 与 RichTextBlock，不会移动贴纸或 Icon。
- 右侧“组件”标签可添加文字、Icon 和贴纸；点击放到页面中央，也可拖到画布目标位置。
- 图片、文字、Icon 和贴纸都能拖动、使用八向控制点缩放、用旋转手柄旋转，并吸附到页面边距、中心、其他 Block 和常用角度。
- “上移一层/下移一层”按同一个 Block 数组调整跨类型图层；也可复制或删除当前 Block。页面栏可新增、移动或删除内容页，封面不能删除。
- 缩放工具只改变编辑视图，不改变 PDF。

快捷键：

- `Ctrl/Cmd + Z`：撤销；`Ctrl/Cmd + Shift + Z`：重做。
- 方向键：微移选中 Block；`Shift + 方向键`：快速移动。
- `Ctrl/Cmd + D`：复制选中 Block。
- `Delete` / `Backspace`：删除选中 Block。

## 6. 裁剪、滤镜和蒙版

选中图片 Block 后在“编辑”标签点击“裁剪与美化”：

- 拖动取景区，调整框内缩放和 -180°–180° 框内旋转。
- 水平或垂直翻转。这与画布上的整个元素旋转是两个独立概念。
- 使用原图、鲜亮、暖阳、清透、胶片、黑白、柔和、高对比预设。
- 精细调整亮度、对比度、饱和度、色相、复古、黑白、柔焦和暗角。
- 选择直角、圆角、圆形、拱门、撕纸边、邮票边或胶片框蒙版。

编辑器使用草稿状态。“取消”不修改文档；“应用到照片”将本次裁剪、滤镜和蒙版合并为一次可撤销修改。所有效果都是非破坏性参数，不会改写原图。

## 7. 富文本、装饰、主题和自动保存

- 封面标题、副标题、日期和页面文字都是普通文字 Block。选中文字后，可设置字体、字号、颜色、粗体、斜体、下划线、对齐、行距和项目符号/编号列表。
- 照片说明仍依附于图片 Block，可在图片编辑面板中显示或隐藏。
- Icon 可修改颜色；选中 Icon 或贴纸后从组件库选择同类资源，会保留原 Block 的位置、尺寸、旋转和图层，只替换内容。
- 主题作用于整本相册，但不改变应用外壳。
- 文档修改会在短暂停顿后自动保存。顶部显示“正在保存”、“已保存”或持续的失败/重试入口。
- 返回项目首页、切页、预览、导出或关闭桌面窗口前，应用会先提交当前聚焦的照片说明和富文本草稿并等待保存。

## 8. 预览与导出

点击“预览”可逐页检查封面和所有内容页。编辑、缩略图、预览和打印共用同一个 Block 渲染链，因此三类 Block 的几何、文字样式、裁剪、滤镜和蒙版保持一致。

- 桌面版：点击“导出 PDF”并选择保存位置。输出包含封面，并使用创建项目时选择的物理尺寸。
- 浏览器版：点击“打印 / PDF”，然后在系统打印面板中选择打印机或“保存为 PDF”。

导出期间请保持窗口打开，直到显示完成。

## 9. 备份与故障排查

### 桌面项目备份

关闭项目后，将整个 `.album-project/` 复制到另一块磁盘。`backups/` 只保留最近的 manifest 备份，不包含额外原图副本，不能代替整体备份。

### 照片缺失

桌面版可在素材库重新定位原图的另一份副本。应用会校验 SHA-256 内容指纹，选错图时不会覆盖记录。浏览器版当前不提供重新定位。

### 启动失败或白屏

桌面版会捕获主页加载、preload 和 renderer 异常，显示可复制的中文错误。选择“复制错误并退出”，将内容发给维护者。已打包应用重复启动时会聚焦现有窗口；开发启动器若已在运行，请直接使用现有窗口。

### 浏览器项目不见了

确认仍使用同一浏览器、同一用户配置和同一 origin。如果站点数据已被清理，当前没有自动恢复途径。

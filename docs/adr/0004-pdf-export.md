# ADR 0004：整册 PDF 导出

- 状态：已接受
- 日期：2026-08-15

## 决策

编辑、预览和打印共用 `AlbumPageView` 与同一项目模型。renderer 常驻一个仅在打印媒体中显示的整册视图；导出前等待打包字体和全部图片完成解码，再由 Electron `printToPDF` 生成 A4 横向、零边距、含背景的 PDF。

PDF 先写入同目录 `.partial` 文件，成功后才改为最终文件名。界面只展示“准备资源 / 生成 PDF / 写入完成”等真实阶段，不伪造 Electron 没有提供的逐页进度。

## 原因与后果

共用页面渲染避免编辑、预览和 PDF 漂移。代价是长相册导出时 renderer 会同时挂载全部打印页面，需要用私有 185-placement 样本持续检查内存。

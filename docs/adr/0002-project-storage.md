# ADR 0002：项目目录与素材存储

- 状态：已接受
- 日期：2026-08-15

## 决策

一个相册项目是用户选择位置下的 `名称.album-project/` 文件夹。权威数据存于 `manifest.json`；原图按 SHA-256 去重复制到 `assets/original/`，预览图是可重建缓存。manifest 不允许 Base64 图片和绝对素材路径。

每张照片在页面上是独立 slot；重复照片共享 Asset，但不会合并 placement。保存由 main 进程按项目串行执行，通过 revision 拒绝过期快照，临时文件写完后原子改名，并保留最近 5 份 manifest 备份。

## 原因与后果

项目可整体复制、备份和离线打开；源照片永不被修改。相比单一 JSON，多文件目录更适合大相册，但用户移动目录时需要整体移动项目文件夹。
